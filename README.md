# ООП на C#
### Цель при написании этого репозитория:
1. Освоить принцыпы объектно-ориентированного программирования: наследование, полиморфизм, инкапсуляцию.

2. Изучить применение паттерна проектирования Singleton на примре создания иерархии классов животных.

### Требования которые были реализованны:
+ Базовый класс `Animal` должен быть абстраутным или виртуальным, с матодом `GrtInfo()` помеченнм как `virtual`. !!!
+ В классах-наследниках исполььзуется ключевое слово `override` для переопределения метода. !!!
+ Для свойства, уникального каждого подтипа, возможно использование автосвойства или поля с проверкой. !!!
+ Singleton должен гарантировать, что существует только один экземпляр класса `AnimalManager`, представляя глобальую точку доступа к нему. !!!
+ Консольное меню должно быть простым и понятным, обрабатывать некорректный ввод. !!!
+ При создании объекта наследника используетс конструктор с параметрами для инициализации всех полей. !!!
+ Метод `GetInfo()` возвращает форматированную строку. !!!
+ Продумман поиск животного через меню. !!!
