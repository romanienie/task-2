# task-2
Задание 2 - ООП на С#
Цель работы
Освоить принципы объектно-ориентированного программирования: наследование, полиморфизм, инкапсуляцию, а также изучить применение паттерна проектирования Singleton на примере создания иерархии классов животных.
Задание
Создать базовый класс Animal, который содержит общие характеристики для всех животных:
Кличка (строка)
Возраст (целое число)
Среда обитания (строка, например, «лес», «водоём», «пустыня»)
Тип питания (строка, например, «хищник», «травоядное», «всеядное»)
Дополнительные поля по желанию (например, вес, окрас).
Создать классы-наследники, представляющие различные подтипы животных:
Mammal (млекопитающее) — добавить уникальное свойство, например, hasFur (наличие шерсти, логическое значение).
Bird (птица) — добавить свойство wingSpan (размах крыльев, число с плавающей точкой).
Fish (рыба) — добавить свойство waterType (тип воды: пресная/морская, строка).
Reptile (пресмыкающееся) — добавить свойство isVenomous (ядовитость, логическое значение).
Amphibian (земноводное) — добавить свойство skinMoisture (влажность кожи, строка или число).
В каждом классе переопределить метод GetInfo(), который возвращает строку с полной информацией о животном, включая уникальные свойства.
Создать класс AnimalManager (или ZooManager), реализованный как Singleton. Этот класс должен отвечать за:
Хранение списка животных (например, в коллекции List<Animal>).
Добавление новых животных (создание экземпляров нужного подтипа).
Вывод информации о всех животных или о конкретном животном по индексу/имени.
Предоставление меню для взаимодействия с пользователем через консоль.
В методе Main продемонстрировать работу программы:
Создать несколько объектов разных подтипов животных.
Добавить их в менеджер (через Singleton).
Вызвать меню, позволяющее пользователю просматривать информацию о животных, добавлять новых или выходить из программы.
Требования к реализации
Базовый класс Animal должен быть абстрактным или виртуальным, с методом GetInfo() помеченным как virtual.
В классах-наследниках использовать ключевое слово override для переопределения метода.
Для свойства, уникального для каждого подтипа, можно использовать автосвойства или поля с проверкой.
Singleton должен гарантировать, что существует только один экземпляр класса AnimalManager, предоставляя глобальную точку доступа к нему (например, через статическое свойство Instance).
Консольное меню должно быть простым и понятным, обрабатывать некорректный ввод.
При создании объектов наследников используйте конструкторы с параметрами для инициализации всех полей.
Метод GetInfo() должен возвращать форматированную строку, например:
"Кличка: Барсик, Возраст: 5, Среда: лес, Питание: хищник, Тип: Млекопитающее, Шерсть: есть".
Продумайте, как пользователь будет выбирать тип животного при добавлении через меню.
